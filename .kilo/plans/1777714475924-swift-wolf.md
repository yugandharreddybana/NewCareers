# Plan: Fix Login Page Reload Loop + Dev Mode Auth Bypass

## Issues Identified

### Issue 1: Login page loading multiple times (development mode)
**Root Causes:**
- React 18 StrictMode double-rendering in development
- `AuthProvider` state initializer reads from `localStorage` synchronously
- `useEffect` in `AuthProvider` persists user to `localStorage` on every user change
- Combined with PWA precaching, this can cause render loops in dev mode
- No dev bypass logic in `AuthContext` or `ProtectedRoute`

### Issue 2: Development mode auth bypass not functional
**Current State:**
- `.env.development` has `VITE_DEV_BYPASS_GUARDS=true` ✅
- `vite-env.d.ts` declares the env var ✅
- `DevModeBanner` component exists but is never imported/used ❌
- `ProtectedRoute` doesn't check the bypass flag ❌
- `AuthContext` doesn't leverage the bypass flag ❌

## Solution Implemented

### Part A: AuthContext — dev bypass support ✅
- Added `VITE_DEV_BYPASS_GUARDS` env flag check
- When bypass is active:
  - Auto-sets mock user from state initializer (no localStorage read)
  - `signIn`/`signUp`/`signOut` short-circuit without backend calls
  - `useEffect` skips localStorage writes (prevents render loops)
- When bypass is inactive: normal auth flow unchanged

### Part B: ProtectedRoute — respect bypass flag ✅
- Checks `VITE_DEV_BYPASS_GUARDS` before auth checks
- In bypass mode: renders `AppShell` directly (no loading spinner, no redirect)
- Normal mode: unchanged behavior (loading → user check → redirect)

### Part C: DevModeBanner — integrated into AppShell ✅
- Imported in `AppShell.tsx` and rendered at bottom
- Banner already had internal `DEV_BYPASS` check; visible only when flag is true

### Part D: Login/Signup — bypass-aware redirects ✅
- `Login.tsx`: bypass mode → skips auth call, redirects to `/dashboard`
- `Signup.tsx`: bypass mode → skips auth call, redirects to `/onboarding`

## Files Modified ✅

1. `frontend/src/context/AuthContext.tsx` - Added dev bypass logic (useState initializer, useEffect, signIn/signUp/signOut)
2. `frontend/src/components/ProtectedRoute.tsx` - Early return for DEV_BYPASS
3. `frontend/src/components/layout/AppShell.tsx` - Import + render DevModeBanner
4. `frontend/src/pages/Login.tsx` - Bypass-aware submit handler
5. `frontend/src/pages/Signup.tsx` - Bypass-aware submit handler

## Behavior

**Dev Mode (`VITE_DEV_BYPASS_GUARDS=true` in `.env.development`):**
- Orange DEV MODE banner visible at bottom of screen
- Direct navigation to any route (e.g., `/dashboard`) loads immediately
- No authentication required
- No localStorage reads/writes → no render loops
- Login/Signup forms auto-redirect (skip backend)

**Production Mode (`VITE_DEV_BYPASS_GUARDS=false` or unset):**
- Normal auth flow (login → ProtectedRoute → AppShell)
- No banner visible
- localStorage used for persistence
- All backend auth calls active

## Testing

- Run `npm run dev` → orange DEV MODE banner appears
- Navigate directly to `/dashboard` without login → loads (bypass)
- Navigate to `/login` → can still submit (auto-redirects to dashboard)
- Navigate to `/signup` → can still submit (auto-redirects to onboarding)
- No console errors or infinite loops
