# Security Exceptions & False Positives

This document outlines the known false positives generated by automated security scanners (e.g., 007 Audit) on this repository.

## Command & Code Injection
- **Pattern:** `exec_usage` / `py_exec_any` / `child_process_exec`
- **Instances:** `frontend/src/lib/*.ts`, `playwright-report/index.html`
- **Justification:** The scanner incorrectly flags JavaScript's `RegExp.prototype.exec()` method as a command execution vulnerability. These instances are purely regex evaluations and pose no injection risk.

## SQL Injection
- **Pattern:** `sql_percent_format`
- **Instances:** `backend/ingest_permit_stats.py`
- **Justification:** The scanner flags the `%s` placeholder used in psycopg2's `.execute("... %s", (val,))`. This is the standard, secure, and driver-recommended way to perform parameterized queries in psycopg2 and is *not* string interpolation.

## SSRF (Server-Side Request Forgery)
- **Instances:** `backend/ingest_permit_stats.py`, `backend/src/main/java/com/careerops/service/sources/company/PlaywrightCareerClient.java`
- **Justification:** These modules are web scrapers designed explicitly to make outbound HTTP requests to external domains (e.g., `enterprise.gov.ie`). They do not accept arbitrary user-provided URLs as targets.

## Hardcoded Secrets
- **Instances:** `.env`, `docker-compose.yml`
- **Justification:** 
  - `.env` is properly listed in `.gitignore` and only exists locally for development; it is not committed to source control.
  - `docker-compose.yml` uses standard default fallbacks (e.g., `${POSTGRES_PASSWORD:-admin}`) strictly for local development ease. Production deployments override these with actual secrets.

## Database Migration & Fix Scripts
- **Pattern:** String formatting in SQL construction (`sql_fstring`, `exec`)
- **Instances:** `backend/fix_*.py` (e.g., `fix_indexes.py`, `fix_arrays.py`)
- **Justification:** These are one-off local data migration and utility scripts. They are not exposed to untrusted user input, making the string concatenation/formatting harmless and intentional for generating DDL statements.

## Sandbox & Tooling Skills
- **Pattern:** `child_process_exec`, Path Traversal, `py_exec_any`, `sql_fstring`
- **Instances:** `skills/ui-ux-pro-max-skill-main/**`
- **Justification:** This directory contains agent capabilities and sandbox scripts (e.g., `_sync_all.py`, `extract-colors.cjs`). They inherently require executing local commands and reading/writing filesystem contents. They run in local agent environments and are not exposed as a service attack surface.
